UNDERSTANDING FILE PERMISSION

Every file has 3 permission set, such as: owner,group,others
owner can read and write and execute file
group can read and execute file
others can read the file only

operations in file: read(r), write(w), execute(x);

example: -rwxr-xr--
owner= rwx full access
group= r-x read+execute
others= r read only

//-------------------------------------------------

chmod: changing permission
user u,group g, others o

read=4,write=2,execute 1...(total 7)(group 5)(others 5)
chmod 755 fileName: user,grp,others

//---------------------------------------------------

chown user:group file: change owner & group
chown -R user folder: change recursively(entire folder)
